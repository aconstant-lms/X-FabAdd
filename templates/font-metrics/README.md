# Font metrics (not for installation)

Latin-only subsets of Space Grotesk and Inter (SIL Open Font License 1.1), used by
`tools/xfab.py restyle` to measure text and shrink titles or boxes that would overflow.
They lack Greek, superscripts and arrows: **do not install them**. Install the full fonts
from https://fonts.google.com/specimen/Inter and https://fonts.google.com/specimen/Space+Grotesk
(the `static` folders).
